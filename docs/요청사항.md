# 남은 실 처방전 — 요청사항 정리

남은 뜨개실을 대충 입력하면 그 실로 뜰 수 있는 무늬와 작품을 추천하고, 도안과 단수 세기까지 도와주는 웹 페이지.
파일 하나(`index.html`)로 된 페이지이고, AI 없이 규칙과 계산만으로 동작한다.

---

## 0. 작업 방식 요청 (꼭 지킬 것)

- **답변과 중간 메시지 모두 한국어로만** 쓴다. 영어로 말하지 않는다.
- 요청이 여러 개면 빠뜨린 게 없는지 체크리스트로 확인하면서 꼼꼼히 작업한다.
- 사용자가 등록한 실 데이터는 업데이트해도 날아가면 안 된다 (저장 키·데이터 형식 유지).

## 1. 요청 순서대로 정리

| # | 요청 | 반영한 내용 |
|---|---|---|
| 1 | 남은 실 양을 보고 만들기 좋은 도안을 추천하는 페이지 | 실 바구니 → 무늬 추천 → 작품 추천 구조. AI 없이 굵기·양 규칙으로 계산 |
| 2 | 굵기·소재·색·양을 정확히 입력하기 어려우니 디테일 없이 | 굵기 3단계(가는/보통/굵은, 바늘 호수 안내), 양은 뭉치 크기(자투리 5g·탁구공 15g·귤 30g·주먹 50g·큰 볼 100g) × 개수, 저울 g 입력은 선택 |
| 3 | 완성품뿐 아니라 어떤 무늬(패턴)를 뜰 수 있는지도 | 무늬별 실 소모율·어울리는 굵기·질감 규칙으로 무늬 추천, 무늬 → 작품 연결 |
| 4 | 직접 만들어 줘 (대바늘/코바늘 둘 다) | 상단 토글로 대바늘·코바늘 전환 |
| 5 | 무늬를 그림으로 보여 주기, 페이지가 너무 길다 → 앱처럼 하단 내비게이션 | 무늬마다 뜨개 조직을 캔버스로 그림, 하단 탭 구조로 개편 |
| 6 | 가진 실 색으로 완성 미리보기 | 비니·머플러·장갑·스웨터·가방·인형 등 작품 실루엣에 무늬+내 실 색을 입힌 완성 미리보기, 메인 색 선택 |
| 7 | 실 삭제 기능 (기본 예시 실 지우기) | 실마다 수정·삭제 버튼, '예시 실 모두 지우기', 삭제 후 5초간 되돌리기 |
| 8 | 자주색이 없음 → 색 다양화, 색 직접 선택, 업데이트 시 데이터 유지 | 색 25가지 + '직접 고르기'(컬러 피커, 가까운 색 이름 자동: "보라 계열"), 실 수정 기능, 저장 키 유지 |
| 9 | 작품 탭이 너무 길다 → 펼치는 형태 | '어울리는 무늬 N개'를 접었다 펼치는 방식 |
| 10 | 무늬를 어떻게 뜨는지(도안) + 코·단수 세기 도우미 | 무늬별 도안(코 잡기·단별 방법·기호 도안), '단수 세기' 탭 |
| 11 | 지금 실로 무늬를 얼마만큼 뜰 수 있는지 | 무늬 카드에 '이 실로 약 40×40cm', 상세에 '폭 20cm면 길이 약 70cm' |
| 12 | 다른 기기에서도 보고 싶다 (깃허브 필요?) | claude.ai 계정 저장으로 기기 간 동기화 (아래 기술 메모 참고) |
| 13 | 추천 무늬 말고 전체 무늬도 | 무늬 탭에 '추천 무늬 / 전체 무늬' 전환, 안 맞는 무늬는 흐리게 + 이유 표시 |
| 14 | 작품 리스트 여전히 김 | 종류 필터(소품/모자·워머/목도리·담요/옷/가방/인형), 카드 압축, '작게 뜨면 될 수도 있는 것'은 접기 |
| 15 | 별표 등으로 진행 중인 무늬·작품 표시 | 무늬·작품·상세에 ☆ 별표(맨 위 고정), 카운터 있는 항목에 '뜨는 중' 배지 |
| 16 | '어울리는 무늬 N개' 버튼 가운데 정렬이 이상함 | 카드 하단 전체 폭 + 왼쪽 정렬, 줄바꿈 없음 |
| 17 | 단수 셀 때 뜨는 도안이 시각적으로 보이게, 먼저 어떻게 뜰지 입력받기 | '어떻게 뜰까요?' 설정 화면 + 카운터에 편물 진행 그림 |
| 18 | 다크 모드를 기본으로 (기기 설정 따라 바뀌는 게 이상함) | 기기 설정과 관계없이 항상 다크로 고정 — **파일에는 반영했지만 화면 확인·게시는 아직 안 함** |
| 19 | 이 대화를 Claude Code로 옮기고 깃허브 연결 | 이 문서와 HTML로 넘겨서 진행 |

## 2. 화면 구성 (하단 탭 4개)

### 상단
- 제목 '남은 실 처방전', 뜨개질 V자 코 띠 장식
- 대바늘 / 코바늘 전환 (전환하면 무늬·작품·도안이 모두 바뀜)

### ① 내 실 (바구니)
- 굵기별 합계(g, 대략 m)
- 실 목록: 굵기 · 색 이름 · 양 · 질감, 수정·삭제 버튼 (폰에서는 아이콘만)
- '+ 실 담기' 바텀시트: 굵기(3단계, 젓가락 비교 팁) / 뭉치 크기 × 개수 또는 저울 g / 질감(매끈·보송) / 색(25색 + 직접 고르기, 선택한 색 이름 표시)
- 처음엔 예시 실 4개가 있고, 내 실을 담거나 '예시 실 모두 지우기'를 누르면 사라짐
- 저장 상태 표시 (계정에 저장됨 / 이 브라우저에만 저장됨)

### ② 무늬
- 굵기 그룹 칩(가는 실/보통 실/굵은 실), '가는 실 두 가닥 합사' 옵션
- '추천 무늬 / 전체 무늬' 전환
- '가장 알뜰한 조합' 카드 (가진 실을 가장 많이 쓰는 무늬+작품, 완성 미리보기 썸네일)
- 무늬 카드: 내 실 색으로 그린 조직 그림, 이름, '이 실로 약 ○×○cm', 특징, 가능한 작품 수, 별표, '뜨는 중' 배지
- 무늬 상세 바텀시트:
  - 완성 미리보기(작품 선택 시 바뀜) + 무늬 확대 원형 썸네일
  - 메인 색 고르기 (고른 색에 따라 그림과 계산이 바뀜)
  - 뜰 수 있는 크기 문장, 실 소모·난이도·바늘 호수 칩, 설명
  - '이 무늬로 뜨기 시작' (카운터가 있으면 '이어서 뜨기')
  - 이 무늬로 뜰 수 있는 작품 목록 (충분해요/빠듯해요/조금 모자랄 수도)
  - **도안**: 코 잡기, 처음 한 번 뜨는 단, 반복 단, 원통 팁, 요령, 기호 도안

### ③ 작품
- 종류 필터 칩 (개수 표시, 0개 종류는 숨김)
- 작품 카드: 완성 미리보기 썸네일, 이름, 상태, 필요량, '○○로 뜨면 ○g 남아요', 별표, '뜨는 중'
- '어울리는 무늬 N개' 펼치기 → 무늬 칩(누르면 상세)
- '작게 뜨면 될 수도 있는 것', '실이 더 있으면 뜰 수 있는 것'은 접어서 표시

### ④ 단수 세기
- 카운터 목록 (무늬·작품·진행률 막대)
- **뜨기 전 설정 '어떻게 뜰까요?'**
  - 무엇을 뜰지 (작품 칩 또는 '정하지 않음', 작품마다 기본 크기)
  - 왕복(평면) / 원통(둘레) — 원통 작품은 원통이 기본, 원통이면 도안도 원통용으로 바뀜
  - 폭(둘레) cm → 콧수 (무늬 배수로 맞춤, 예: 꽈배기 8의 배수)
  - 길이 cm → 목표 단수 (무늬 한 번이 끝나는 단으로 맞춤)
  - 필요한 실 양 vs 가진 실 비교
  - 숫자는 직접 수정 가능, 뜨는 중에도 '뜨는 방법 바꾸기'로 수정
  - 순서형 도안(아미구루미·꽃)은 단수가 정해져 있고, 그래니·C2C는 목표 단수만 입력
- **카운터 화면**
  - 편물 진행 그림: 완성 크기를 점선으로, 뜬 단만큼 내 실 색 무늬가 아래에서 차오름, 현재 단에 바늘(코바늘이면 코바늘)과 '지금 ○단' 표시, 콧수·폭 표시
  - 진행률: '30 / 55단 · 55% · 약 12cm 떴어요 · 남은 길이 약 11cm'
  - 순서형 도안은 단 번호 칸이 하나씩 채워지는 방식
  - '지금 뜰 단' 크게 + 이번 단에 할 일 + 다음 단 미리보기
  - '○단 다 떴어요 +1' 큰 버튼, 1단 되돌리기, 처음부터(두 번 눌러 확인)
  - 코 세기 (+/−, 단 넘기면 0으로 자동 초기화 옵션)
  - 화면 꺼짐 방지 (Wake Lock)
  - 기호 도안에서 지금 뜰 줄 강조, '도안 전체 보기'
  - 카운터 삭제 (두 번 눌러 확인)

## 3. 데이터·규칙

### 무늬 (대바늘 12 / 코바늘 13)
- 대바늘: 메리야스, 가터, 고무, 멍석, 바스켓위브, 와플, 꽈배기, 비침무늬, 브리오슈, 줄무늬, 걸러뜨기 배색, 페어아일
- 코바늘: 짧은뜨기, 한길긴뜨기, 린넨 스티치, 그래니 스퀘어, 부채, 그물, 팝콘, 코바늘 와플, C2C 배색, 줄무늬, 꽃 모티브, 아미구루미, 레이스
- 무늬별 속성: 실 소모율(f), 어울리는 굵기, 허용 질감(보송한 실 가능 여부), 필요한 색 수, 난이도, 어울리는 작품 태그, 콧수 배수(왕복/원통)

### 작품 (대바늘 16 / 코바늘 16)
- 굵기별 필요량(g, 메리야스 기준). 예) 대바늘 비니 70/100/140g, 머플러 150/200/280g
- 작품별 기본 크기(폭×길이 cm)와 원통 여부 — 설정 화면 기본값

### 판정
- 필요량 = 작품 기본량 × 무늬 소모율
- 가진 양 ÷ 필요량: 1.15 이상 '충분해요', 0.95 이상 '빠듯해요', 0.75 이상 '조금 모자랄 수도'
- 한 색 무늬는 메인 색 한 가지 양으로, 배색 무늬는 해당 굵기 전체 양으로 계산 (그래니·꽃은 색이 2개 이상이면 배색)
- 보송한 실(모헤어 등)은 복잡한 무늬에서 제외

### 크기·게이지 (어림값)
- 100cm²당 g: 가는 4 / 보통 6 / 굵은 8.5 (코바늘 ×1.3, × 무늬 소모율)
- 10cm당 코·단: 대바늘 가는 28·36 / 보통 18·24 / 굵은 12·16, 코바늘 가는 24·26 / 보통 16·18 / 굵은 10·11 (긴뜨기류는 단 수 ×0.5 등 무늬별 보정)

## 4. 기술 메모 (Claude Code에서 이어서 작업할 때)

- 파일 하나에 HTML·CSS·JS 모두 포함. 외부 리소스는 구글 폰트(Hahmlet, IBM Plex Sans KR, IBM Plex Mono)만 사용.
- 무늬 그림·완성 미리보기·편물 진행 그림은 모두 캔버스로 그림 (`DRAW`, `drawProduct`, `drawProgress`).
- **저장**
  - 브라우저: `localStorage` 키 `leftover-yarn-v1` (실·별표·카운터·탭 등). 이 키와 데이터 형식을 바꾸면 기존 데이터가 사라지니 유지할 것.
  - 계정 동기화: claude.ai 아티팩트에서만 동작하는 `window.claude.use("db")` / `use("user")` 사용. 문서 경로 `data/users/<id>/state`, `updatedAt`이 더 최신인 쪽을 사용.
  - **깃허브 Pages 등 claude.ai 밖에서 열면** `window.claude`가 없어서 자동으로 '이 브라우저에만 저장' 모드로 동작함 (오류 없음). 기기 간 동기화가 필요하면 Firebase·Supabase 같은 별도 저장소를 붙여야 함.
- 함께 드리는 `index.html`은 깃허브에 바로 올릴 수 있게 `<!doctype html>`, `<head>`, viewport 메타를 감싼 버전. (claude.ai 아티팩트 원본은 이 껍데기 없이 본문만 있는 형태)
- 현재 claude.ai 링크(아티팩트)는 18번(다크 모드 고정) **이전** 버전까지 게시된 상태.

## 배색 변경 (Soft Linen)
- 18번(다크 고정)을 대신해요: 밝은 웜화이트가 기본, 기기 설정이 어둡게면 자동으로 어둡게(먹색 + 연라벤더).
- 탭 모양(실 굵기·보기 전환) 선택 = 흰색으로 떠 보이게, pill 모양(추천/전체/내 도안/★, 작품 종류) 선택 = 라벤더 채움.
- 무늬 그림: 코를 크게, 실 색은 그대로 한 톤 부드럽게, 바탕은 실 색의 연한 톤. 자간 살짝 좁게, 카드 테두리 대신 옅은 그림자.
